### あきらめたコード ###  
  
最初のアイデアは、重複しているノードを比較して、後ろのノードで前のノードを置き換え、  
その後もう一度処理を行い、自分自身も含めて削除する、というものでした。  
しかし、実際に書いてみるとエラーが出てしまいました。  

```python
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev = None
        node = head
        while node is not None and node.next is not None:
            if node.val == node.next.val:
                node.next = node.next.next
                node.next = prev
                node = prev
            else:
                node = node.next
        return head
```

### 解答
```python
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(None)
        result = dummy
        node = head
        while node:
            if node.next and node.val == node.next.val:
                while node.next and node.val == node.next.val:
                    node.next = node.next.next
                node = node.next
                continue
            else:
                result.next = ListNode(node.val)
                result = result.next
                node = node.next
                continue
        return dummy.next
```

## step 2  

＃dummy もう一度調べます  

1. prev.next を更新する だけで削除が可能になる
1. 先頭でも途中でも同じ処理で対応できる
1. コードがシンプルで読みやすくなる  
--> LinkedList の削除処理を安全かつシンプルにするために非常に有効である。
   
＃continue 調べます  

1. 条件ごとに処理をはっきり分離できる
1. 不要なネスト（入れ子構造）を減らせる
1. メインロジック（削除処理）を外側に保てる  
--> continue を使うことで、「このケースは処理しない」と明確に分岐でき、  
   ネストを浅く保ちながらコードの可読性と保守性を向上させることができる。
