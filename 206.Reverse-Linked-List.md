## step 1
この問題を見たとき、まず「お皿を積み重ねるイメージ」で考えました。  
手元にあるお皿の山から1枚ずつ取り出して別の場所に積み重ねていきます。  
すると最後に置いたお皿が一番上になります。  
その後、新しくできた山の一番上から順番にお皿を取り出して別の場所へ移していくことで、  
元とは逆順の並びを作れるのではないかと考えました。  
つまり、Stack を使って Linked List を逆順にする方法を最初に思いつきました。  

しかし、Python の文法や Linked List の基本的な操作にまだ慣れておらず、最後まで実装を完成させることができませんでした。

## step 2

### 解きなおす
まず、ListNodeの定義や基本的な扱い方を改めて理解し、  
その後はGPTのサポートを受けながら、このような解答を作成しました。  

感想：最初に一度 pop() を行わなくても実装できる、より良い方法があるのではないかと考えました。
```python
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        stack = []
        while head:
            stack.append(head.val)
            head = head.next
        if not stack:
            return None
        # 🔥 最初のノード（Linked Listの先頭）を作成する
        new_stack = ListNode(stack.pop())
        cur = new_stack
        while stack:
            cur.next = ListNode(stack.pop())
            cur = cur.next
        return new_stack
＃空間計算量 O(n)
＃時間計算量 O(n)
```

```python
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        node = head
        last_fixed_node = None
        while node is not None:
            not_fixed_node = node.next
            node.next = last_fixed_node
            last_fixed_node = node
            node = not_fixed_node
        return last_fixed_node
＃空間計算量 O(1)
＃時間計算量 O(n)
```
この中で特に重要な一文
```
node.next = last_fixed_node
```
現在のノードの next は、すでに反転が完了している部分の連結リスト（last_fixed_node）を指すように変更される。  
たとえば　　
``` 
last_fixed_node:
3 → 2 → 1 → None
current node:
4 → 5 → None
反転後
4 → 3 → 2 → 1 → None
5 → None
```

### 再帰
https://neetcode.io/solutions/reverse-linked-list  
再帰を使った解法もありましたが、理解するのに少し時間がかかりました。  
ただ、個人的にはあまり直感的ではありませんでした。  

処理としては、最後のノードまで一度たどり着き、その後の戻りの過程で各ノードの next を反転させていると理解しました。  
また、if の中で自分自身の関数を呼び出すことで再帰が成立している点が、この解法の本質だと感じました。  
``` python
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return None

        newHead = head
        if head.next:
            newHead = self.reverseList(head.next)
            head.next.next = head
        head.next = None

        return newHead
```
