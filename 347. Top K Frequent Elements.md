まず Counter で nums の各数字の出現回数（num→freq）を数え、min-heap に (freq, num) の形で順番に追加する。 
heap は最小値が優先されるため、サイズが k を超えたら最も頻度の小さい要素を削除し続けることで、 
最終的に出現頻度の高い上位 k 個だけが残り、最後に heap から num を取り出して結果として返す。 
```python
import heapq
from typing import List
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count = Counter(nums)
        heap = []

        for num, freq in count.items():
            heapq.heappush(heap, (freq, num))

            if len(heap) > k:
                heapq.heappop(heap)

        return [num for freq, num in heap]
```

各数字の出現回数を数えてから、その回数で並び替え、上位K個を取り出す。  
```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        counts = {}

        for num in nums:
            counts[num] = 1 + counts.get(num, 0)
        
        ordered = sorted(counts, key=counts.get, reverse=True)
        return ordered[:k]
```
